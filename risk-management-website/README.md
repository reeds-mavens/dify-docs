# Dromos Risk Management Website

Een moderne, responsive website voor Dromos Risk Management, gebouwd met Next.js, React, TypeScript en Tailwind CSS.

## Features

- 🏠 Home pagina met services en testimonials
- 📝 Blog met 4 artikelen
- 👤 Over ons pagina
- 📧 Contact pagina met werkend formulier
- 📱 Volledig responsive met hamburger menu
- 🎨 Modern en professioneel design

## Getting Started

Installeer dependencies:

```bash
npm install
```

Start de development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in je browser.

## Build

```bash
npm run build
npm start
```

## Tech Stack

- **Framework**: Next.js 14
- **UI Library**: React 18
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Icons**: React Icons
- **Email**: EmailJS
